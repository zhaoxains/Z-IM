# Z-IM Mobile Prototype

这是一个基于 Flutter 的个人端 IM 原型工程，目标平台为 `H5 + Android + iOS`。

## 当前范围

- Cupertino 风格登录页
- 消息页
- 聊天详情页
- 通讯录页
- 新的朋友页
- 发现页
- 我的页
- 创建群聊页
- 全量 Mock 数据闭环

## 推荐后续架构

- 客户端：Flutter
- 服务端：Go
- 数据库：MySQL
- 缓存：Redis
- 文件存储：MinIO
- 运营后台：Vue 3 + Element Plus

## 本地启动

1. 安装 Flutter SDK
2. 进入 `apps/mobile`
3. 执行 `flutter pub get`
4. 执行 `flutter run`

当前远程环境未安装 Flutter SDK，因此本次提交未执行本地编译验证。
