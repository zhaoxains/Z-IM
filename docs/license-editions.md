# Z-IM 私有化双版本授权方案

## 1. 目标

在纯社交 IM 私有化部署场景下，不按用户数收费，统一使用同一套源码，通过授权密钥和服务端强校验实现：

- 免费私有化版
- 商业授权私有化版

## 2. 设计原则

- 限制逻辑只放服务端，客户端不可信
- 免费版和商业版部署包尽量一致
- 差异只体现在授权文件、密钥和后台配置
- 支持离线私有化部署
- 即使客户拿到源码，默认也只能跑免费能力，商业能力需要正式授权文件

## 3. 授权结构

建议授权文件使用如下结构：

```json
{
  "license_id": "lic_xxx",
  "edition": "free",
  "customer_name": "demo",
  "issued_at": "2026-05-18T00:00:00Z",
  "expire_at": "2099-12-31T23:59:59Z",
  "feature_flags": {
    "multi_party_call": false,
    "e2ee": false,
    "speech_to_text": false,
    "remove_branding": false,
    "custom_branding": false
  },
  "limits": {
    "friend_limit": 200,
    "group_member_limit": 50,
    "single_call_max_minutes": 5,
    "max_file_mb": 20
  },
  "signature": "base64-signature"
}
```

## 4. 校验流程

### 4.1 启动校验

服务端启动时执行：

1. 读取本地授权文件或环境变量
2. 解析授权内容
3. 使用内置公钥验签
4. 校验版本、有效期、签名是否合法
5. 加载到内存配置中心

若授权缺失或校验失败：

- 默认降级到免费版
- 后台授权中心显示异常状态

### 4.2 运行时校验

以下能力必须在服务端运行时再次校验：

- 好友数量上限
- 群人数上限
- 音视频通话时长
- 多人音视频开关
- 文件上传大小
- E2EE 是否允许启用
- 是否允许移除免费版标识
- 是否允许自定义品牌名称

## 5. 免费版限制

### 5.1 社交限制

- 单账号好友上限：200
- 单群人数上限：50

### 5.2 音视频限制

- 仅允许一对一音视频
- 单次通话最长 5 分钟
- 到时自动挂断
- 禁止发起多人音视频

### 5.3 文件与存储限制

- 单文件最大 20MB
- 超出直接拒绝上传

### 5.4 安全功能限制

- 禁止开启端到端加密
- 仅保留基础传输加密

### 5.5 商用限制

- 禁止二次分装售卖
- 客户端展示免费版标识
- 服务端写入免费部署标记
- 不提供官方技术支持能力入口

## 6. 商业版解锁

### 6.1 全量解锁

- 好友数不限制
- 群人数不限制
- 一对一通话不限制时长
- 支持多人音视频
- 支持端到端加密
- 支持多设备自由同步
- 支持语音转文字

### 6.2 品牌与商用能力

- 去除免费版标识
- 支持自定义品牌名 / Logo
- 开放正式商用权限
- 提供版本更新与技术支持

## 7. 服务端拦截点

### 7.1 好友限制

- 在同意好友申请前校验当前好友数
- 超限则返回明确错误码

### 7.2 群人数限制

- 拉人入群前校验目标群成员数
- 超限则阻止新增成员

### 7.3 音视频限制

- 发起多人通话前校验 `multi_party_call`
- 单聊通话开始时写入允许通话截止时间
- 定时任务或会话守护进程到时自动挂断

### 7.4 上传限制

- 文件上传服务在流式接收前校验 `Content-Length`
- 上传完成后再次校验实际文件大小

### 7.5 E2EE 限制

- 创建会话加密配置时校验 `e2ee`
- 免费版直接拒绝开启

## 8. 后台管理要求

授权中心至少包含：

- 当前版本：免费版 / 商业版
- license_id
- 客户名称
- 到期时间
- 已解锁功能
- 当前限制项
- 授权文件导入记录

## 9. 错误码建议

- `LICENSE_INVALID`
- `LICENSE_EXPIRED`
- `LICENSE_FEATURE_DENIED`
- `FRIEND_LIMIT_REACHED`
- `GROUP_MEMBER_LIMIT_REACHED`
- `CALL_DURATION_LIMIT_REACHED`
- `MULTI_CALL_DISABLED`
- `FILE_SIZE_LIMIT_REACHED`
- `E2EE_DISABLED_IN_FREE`

## 10. 推荐实现方式

- 授权文件使用 JSON
- 使用非对称签名做离线验签
- 服务端编译时内置公钥
- 将功能限制集中封装在 `LicenseGuard`
- 所有业务模块通过统一守卫读取授权，不允许各模块自行判断
